**Weverse·Instagram 한국어 라이브 번역 오버레이**는 번역자분들이 직접 작성해 주시는 공개 한국어 번역을 위버스 영상과 CUTIE STREET 멤버의 Instagram 라이브 화면에 자막처럼 표시하는 Chrome·Edge 확장프로그램입니다.
큐티스트리트 번역자분들의 소중한 인간 번역을 팬들이 영상과 함께 더욱 편하게 볼 수 있도록 연결해 주는 프로그램입니다.
인간번역기 사이트 제작자 : 미유히메

- 다운로드 및 소스코드:  
  https://github.com/masudaayano156/weverse-korean-translation-overlay
- 최신 버전: `v1.15.0`
- 지원 브라우저: Chrome, Microsoft Edge

---

## 주요 기능

### 라이브 한국어 번역 표시

- 위버스 또는 지원하는 Instagram 생방송이 시작되면 현재 진행 중인 한국어 번역 세션을 자동으로 찾아 연결합니다.
- 번역자가 입력한 번역을 영상 위에 실시간으로 표시합니다.
- 공개 번역은 WebSocket으로 즉시 받아오며, 연결이 끊기면 같은 번역 서버의 HTTP 조회로 자동 전환하고 재연결합니다.
- 번역이 도착하면 기본적으로 즉시 표시됩니다.
- 필요할 경우 자막을 0.5초·1초·5초 단위로 늦출 수 있습니다.
- 라이브 자막 싱크는 `−120초`까지 늦출 수 있습니다.
- 라이브 싱크는 `−` 버튼으로 현재보다 늦게, `+` 버튼으로 현재보다 빠르게 조절합니다. 아직 도착하지 않은 자막을 미리 표시할 수 없으므로 가장 빠른 값은 `0초`입니다.
- 아직 도착하지 않은 번역을 미리 보여줄 수는 없지만, 시청 환경에 맞춰 더 늦게 표시하는 것은 가능합니다.

### Instagram 라이브 지원

- CUTIE STREET 멤버 8명의 Instagram 라이브 주소를 인식합니다.
- 인스타 ID를 멤버의 본명·이름·별명과 비교하여 현재 진행 중인 번역 세션을 자동으로 선택합니다. 예를 들어 `후리`는 후루사와 리사, `파루땅`은 사쿠라바 하루카로 인식합니다.
- 데스크톱 화면에 영상 왼쪽 빈 공간이 충분하면 번역창을 그 공간에 자동 배치합니다.
- 창이 좁거나 전체 화면이라 왼쪽 공간이 부족하면 영상 영역 안에 안전하게 배치하며, 이후 자유롭게 옮길 수 있습니다.
- 라이브 싱크 조절, 전체 번역 기록, 이모티콘 리액션과 자막 디자인 설정을 위버스 라이브와 동일하게 사용할 수 있습니다.

### 라이브 이모티콘 리액션

- 라이브 인간 번역이 연결된 동안 채팅창 하단에 `🥹 ❤️ 😂 😭 🔥 😮` 버튼이 항상 표시됩니다.
- 버튼은 마우스를 채팅창에 올리지 않아도 보이며, 누른 이모티콘은 영상 위에 바로 떠오릅니다.
- 같은 공개 번역 세션을 보고 있는 인간 번역기 사이트 이용자와 확장프로그램 이용자의 리액션도 함께 표시됩니다.
- 보관 번역을 보는 다시보기와 설정 화면에서는 리액션 버튼이 표시되지 않습니다.

### 다시보기 번역 자동 연결

- 지나간 방송을 보면 번역 사이트의 보관 번역을 자동으로 찾아 표시합니다.
- 위버스 방송 날짜·시각과 번역 세션을 비교하여 알맞은 번역을 선택합니다.
- 위버스 페이지가 이미 받아온 공개 게시물 응답에서 초 단위 `onAirStartAt`을 읽어 자막 시간축으로 사용합니다.
- 정확한 시작 시각을 일시적으로 확인하지 못한 경우에만 번역 세션 시각을 임시 기준으로 사용합니다.
- 자동으로 일치하는 번역을 찾지 못하면 목록에서 직접 번역 세션을 선택할 수도 있습니다.
- 지난 라이브가 위버스의 `/media/...` 주소로 열리는 경우에도 `LIVE 채팅 다시보기`가 있는 방송이면 자동으로 인식합니다.

### 다시보기 자막 싱크 조절

- 영상 재생 위치를 이동하면 자막도 해당 시점으로 따라갑니다.
- 다시보기의 송출 지연과 번역 입력 지연을 기본 영점에 포함해 보정합니다.
- 사용자에게는 방송마다 `0.0초`부터 시작하는 간단한 미세 조정값으로 표시됩니다.
- `−5초`, `−1초`, `−0.5초`, `0초`, `+0.5초`, `+1초`, `+5초` 버튼으로 빠르게 조정할 수 있습니다.
- `+`는 자막을 더 일찍, `−`는 자막을 더 늦게 표시합니다.
- 조절 범위는 최대 ±10분입니다.
- 조정한 싱크는 해당 위버스 방송에만 저장되며, 나중에 같은 방송을 다시 열어도 자동으로 적용됩니다.
- 번역창에 마우스를 올리면 설정을 열지 않아도 빠른 싱크 조절 버튼이 나타납니다.

### 대사 한 줄로 정확하게 맞추기

자동 싱크가 맞지 않는 예외적인 방송은 특정 대사 한 줄을 기준으로 맞출 수 있습니다.

1. 영상에서 해당 대사가 실제로 나오는 순간 일시정지합니다.
2. 번역창의 톱니바퀴를 누릅니다.
3. **다시보기 기준 자막 맞춤**에서 같은 번역 문장을 선택합니다.
4. **선택 자막을 현재 영상 시각에 맞추기**를 누릅니다.

이 기준점은 해당 방송에만 저장됩니다.  
**자동 기준**을 누르면 언제든 방송별 수동 기준점을 삭제할 수 있습니다.

### 광고 시간 자동 처리

- 위버스가 본편과 별도 영상으로 재생하는 광고를 자동으로 구분합니다.
- 광고 중에는 번역을 잠시 숨기고 자막 시간 진행을 멈춥니다.
- 광고가 끝나면 본편의 재생시간을 다시 따라갑니다.
- 광고 길이가 매번 달라도 광고 시간을 자막 싱크에 포함하지 않습니다.

## 자유로운 오버레이 배치

- 왼쪽 위
- 오른쪽 위
- 왼쪽 아래
- 오른쪽 아래

상단의 순환 버튼을 누르면 다음 순서로 위치가 바뀝니다.

`오른쪽 아래 → 왼쪽 아래 → 왼쪽 위 → 오른쪽 위`

원하는 위치가 따로 있다면 번역창 제목 부분을 마우스로 끌어 영상 안팎에서 자유롭게 배치할 수 있습니다. 브라우저 화면 밖으로는 나가지 않습니다.

창의 네 변과 네 모서리를 끌면 너비와 높이도 자유롭게 바꿀 수 있습니다. 창 높이에 따라 화면에 보이는 자막 양이 자연스럽게 달라집니다.

### 위치·크기 잠금

상단의 🔓 버튼을 눌러 🔒 상태로 만들면 다음 동작이 잠깁니다.

- 제목을 끌어서 이동
- 창의 변과 모서리를 이용한 크기 변경

자막 위치를 다 맞춘 뒤 잠가 두면 실수로 창이 움직이거나 크기가 바뀌는 것을 방지할 수 있습니다.

### 영상 클릭 우선

설정에서 **영상 클릭 우선**을 켜면 자막 본문이 마우스 클릭을 가로채지 않습니다.

자막이 영상 위에 있어도 해당 부분을 통과해 영상을 직접 클릭할 수 있습니다. 상단의 위치·잠금·설정·닫기 버튼은 계속 사용할 수 있습니다.

## 전체 번역 기록과 새 자막 알림

- 창에는 현재 높이에 맞는 만큼의 자막이 표시됩니다.
- 마우스 휠로 위로 올리면 지금까지 쌓인 전체 번역을 확인할 수 있습니다.
- 과거 번역을 읽는 동안 새 자막이 도착해도 현재 읽던 위치가 갑자기 맨 아래로 이동하지 않습니다.
- 화면 아래쪽에 `↓ 최신 자막` 버튼이 나타납니다.
- 새 자막이 도착하면 `↓ 최신 자막 · 새 자막 7개`처럼 개수도 함께 표시됩니다.
- 버튼을 누르면 가장 최근 자막으로 부드럽게 이동합니다.

## 번역자 표시

- 번역자 이름 표시는 기본으로 켜져 있습니다.
- 같은 번역자가 계속 번역할 때는 상단에 한 번만 표시합니다.
- 방송 도중 번역자가 교대하면 해당 구간의 실제 번역자로 자동 변경됩니다.
- 과거 자막으로 스크롤하면 현재 보고 있는 구간을 번역한 사람의 이름으로 바뀝니다.
- 원하지 않을 경우 설정에서 번역자 표시를 끌 수 있습니다.

번역자분들의 도움과 노력을 확인할 수 있도록 기본값은 표시 상태입니다.

## 자막 디자인 설정

다음 항목을 원하는 대로 바꿀 수 있습니다.

- 글씨 크기: 12~28px
- 글씨 색상
- 검은색 글자 테두리 표시 여부
- 글자 테두리 굵기: 1~4px
- 배경 투명도: 0~100% (`0%`는 불투명, `100%`는 완전히 투명)
- 채팅창 너비
- 창 테두리 표시 여부
- 초 단위 한국 시간 표시 여부
- 번역자 표시 여부

배경 투명도를 `100%`로 설정하고 창 테두리를 끄면 배경과 부가 레이아웃이 사라지고 자막 글자만 남는 형태로 사용할 수 있습니다.

흰색 자막이 밝은 영상에서 보이지 않을 때는 검은 글자 테두리를 켜면 가독성이 좋아집니다.

설정을 변경한 뒤에는 화면 아래의 **저장하고 번역 보기** 버튼을 누르면 됩니다. 설정값은 브라우저에 저장됩니다.

## 위버스 영상 조작 방해 최소화

- 기본 배치는 영상 진행 막대와 하단 재생 버튼 영역을 피하며, 필요하면 오버레이를 영상 바깥으로 직접 옮길 수 있습니다.
- 위버스 설정 메뉴가 오버레이와 겹치면 번역창이 잠시 자동으로 숨습니다.
- 해상도와 재생 속도 하위 메뉴에서도 계속 숨은 상태를 유지합니다.
- 설정 메뉴를 닫으면 번역창이 기존 위치에 다시 나타납니다.
- 전체 화면이나 위버스 영상 크기가 바뀌면 새로운 영상 영역에 맞춰 자동으로 재배치됩니다.

## 항상 최고 화질로 보기

설정에서 **항상 가능한 최고 화질**을 켤 수 있습니다.

방송이 1080p 등 여러 해상도를 제공하면 가능한 값 중 가장 높은 해상도를 선택합니다. 최고 화질 사용 시 인터넷 데이터 사용량이 늘어날 수 있습니다.

이 기능은 위버스 플레이어 전용이며 Instagram 설정 화면에서는 표시되지 않습니다.

## 상단 버튼 사용법

번역창 상단 버튼은 다음 순서입니다.

- `↗` 원본 번역 사이트 열기
- `⟳` 오른쪽 아래·왼쪽 아래·왼쪽 위·오른쪽 위 위치 순환
- `🔓 / 🔒` 위치와 크기 잠금·해제
- `⚙` 표시 및 자막 싱크 설정
- `×` 번역창 숨기기

`×`를 눌러도 완전히 사라지지 않습니다. 영상 모서리에 작은 **한국어 번역 열기** 버튼이 남으며, 이 버튼을 누르면 다시 표시됩니다.

브라우저 도구 모음의 확장프로그램 아이콘을 눌러 켜고 끌 수도 있습니다.

기본 단축키는 다음과 같습니다.

`Alt + Shift + K`

단축키가 다른 프로그램과 충돌하면 Chrome의 `chrome://extensions/shortcuts`에서 변경할 수 있습니다.

# 설치 방법

## 방법 1: GitHub Releases에서 받기

1. 다음 GitHub 저장소에 접속합니다.  
   https://github.com/masudaayano156/weverse-korean-translation-overlay

2. 화면 오른쪽의 **Releases**를 누릅니다.

3. 가장 최신 버전인 `v1.15.0`을 선택합니다.

4. 페이지 아래의 **Assets**를 펼칩니다.

5. **Source code (zip)**을 눌러 파일을 내려받습니다.

6. 내려받은 ZIP 파일을 마우스 오른쪽 버튼으로 누르고 **압축 풀기** 또는 **모두 압축 풀기**를 선택합니다.

압축파일 안에서 바로 설치하지 말고 반드시 먼저 압축을 풀어야 합니다.

릴리스가 아직 표시되지 않는 경우에는 저장소의 초록색 **Code** 버튼을 누른 뒤 **Download ZIP**을 선택해도 됩니다.

## Chrome 설치

1. Chrome 주소창에 다음 주소를 입력합니다.

   `chrome://extensions`

2. 확장프로그램 관리 화면 오른쪽 위의 **개발자 모드**를 켭니다.

3. 화면 왼쪽 위에 나타나는 **압축해제된 확장 프로그램을 로드합니다** 버튼을 누릅니다.

4. 앞에서 압축을 푼 폴더를 선택합니다.

5. 반드시 `manifest.json` 파일이 바로 들어 있는 폴더를 선택해야 합니다.

   예를 들어 압축을 푼 폴더 안에 같은 이름의 폴더가 한 번 더 있다면, 안쪽 폴더를 선택합니다.

6. 확장프로그램 목록에 **Weverse·Instagram 한국어 라이브 번역 오버레이**가 나타나는지 확인합니다.

7. 이미 위버스 또는 Instagram 라이브 페이지를 열어 두었다면 페이지를 한 번 새로고침합니다.

8. Chrome 오른쪽 위 퍼즐 모양의 확장프로그램 버튼을 누른 뒤, 이 확장프로그램 옆의 고정 버튼을 누르면 아이콘을 항상 표시할 수 있습니다.

## Microsoft Edge 설치

1. Edge 주소창에 다음 주소를 입력합니다.

   `edge://extensions`

2. 확장 관리 화면의 **개발자 모드**를 켭니다.

3. **압축 풀린 파일 로드** 또는 **압축해제된 확장 로드** 버튼을 누릅니다.

4. `manifest.json`이 바로 들어 있는 압축 해제 폴더를 선택합니다.

5. 확장프로그램이 목록에 나타나면 위버스 또는 Instagram 라이브 페이지를 새로고침합니다.

6. Edge 도구 모음의 확장 메뉴에서 아이콘을 고정하면 편하게 켜고 끌 수 있습니다.

## 처음 사용하는 방법

1. 확장프로그램 설치가 끝나면 위버스의 라이브·다시보기 또는 CUTIE STREET 멤버의 Instagram 라이브 페이지를 엽니다.

2. 주소가 다음과 같은 라이브 또는 지난 라이브 페이지인지 확인합니다.

   `https://weverse.io/.../live/...`

   `https://weverse.io/.../media/...` (`LIVE 채팅 다시보기`가 있는 방송)

   `https://www.instagram.com/{멤버 인스타 ID}/live/`

3. 페이지를 새로고침하면 영상 위에 **한국어 실시간 번역** 창이 나타납니다.

4. 번역 세션이 존재하면 방송에 맞는 세션이 자동으로 선택됩니다.

5. 번역이 자동으로 일치하지 않으면 상단 목록에서 올바른 세션을 직접 선택한 뒤 새로고침 버튼을 누릅니다.

6. 톱니바퀴를 눌러 글씨 크기, 색상, 투명도, 위치와 자막 싱크를 설정합니다.

7. 설정을 마친 뒤 **저장하고 번역 보기**를 누릅니다.

## 업데이트 방법

새 버전이 공개되면 다음 순서로 업데이트하는 것이 가장 안전합니다.

1. GitHub에서 새로운 ZIP 파일을 다운로드하고 압축을 풉니다.
2. 기존에 Chrome이 불러오고 있는 확장프로그램 폴더에 새 파일을 덮어씁니다.
3. `chrome://extensions` 또는 `edge://extensions`를 엽니다.
4. 확장프로그램 카드의 새로고침 버튼을 누릅니다.
5. 열려 있던 위버스 페이지도 새로고침합니다.

기존 폴더를 유지하면서 파일을 교체하면 저장한 설정과 설치 상태를 관리하기 편합니다.

## 자막이 나타나지 않을 때

다음 항목을 차례로 확인해 주세요.

1. 현재 주소가 위버스의 `/live/` 페이지, `LIVE 채팅 다시보기`가 있는 `/media/` 페이지 또는 지원 멤버의 Instagram `/{인스타 ID}/live/` 페이지인지 확인합니다.
2. 확장프로그램 관리 화면에서 확장프로그램이 켜져 있는지 확인합니다.
3. 확장프로그램을 새로고침합니다.
4. 현재 라이브 페이지도 새로고침합니다.
5. 영상 모서리에 **한국어 번역 열기** 버튼이 남아 있는지 확인합니다.
6. 브라우저 도구 모음의 확장프로그램 아이콘이나 `Alt + Shift + K`를 눌러봅니다.
7. 번역 세션 목록의 새로고침 버튼을 누릅니다.
8. 해당 방송에 실제 번역 세션이 존재하는지 확인합니다.

라이브 번역은 사람이 직접 입력하기 때문에 실제 발언보다 약간 늦게 도착할 수 있습니다. 해당 방송을 번역하는 사람이 없거나 아직 첫 번역이 등록되지 않았다면 자막이 표시되지 않습니다.

## 개인정보와 보안

- 위버스 로그인 정보, 쿠키, 사용자가 입력한 채팅과 시청 기록을 수집하거나 번역 서버로 전송하지 않습니다.
- Instagram에서는 현재 라이브 주소의 공개 인스타 ID와 화면에 보이는 영상의 위치·크기만 확인합니다. Instagram 댓글, DM, 로그인 정보와 쿠키는 읽거나 번역 서버로 보내지 않습니다.
- 화면 텍스트는 방송 제목·멤버·분 단위 시작 표시를 자동 일치시키는 동안 브라우저 메모리에서만 확인하고 외부로 전송하지 않습니다.
- 별도 서명 키나 비공개 API를 사용하지 않습니다. 위버스 페이지가 이미 받은 게시물 응답을 복제해 해석한 뒤 공개 방송 번호·시작 시각·게시 시각·다시보기 여부만 오버레이에 전달하며, 원래 요청과 응답은 변경하지 않습니다.
- 번역 표시에 필요한 공개 세션 목록, 선택한 세션의 공개 번역 메시지와 라이브 리액션만 `api.cutiestreet.kro.kr`에서 WebSocket으로 읽습니다. 연결이 실패하면 번역 메시지는 같은 서버의 HTTP 조회로 자동 전환합니다.
- 라이브 이모티콘을 직접 누른 경우에만 공개 세션 번호, 선택한 리액션 종류와 무작위 익명 식별 번호 2개를 같은 번역 서버로 보냅니다. 하나는 이 브라우저를 익명으로 구분하고 다른 하나는 해당 클릭의 중복 전송을 구분합니다. 번호에는 위버스 계정·로그인 정보·이름이 들어 있지 않습니다.
- 위치·글씨·표시 설정과 마지막으로 선택한 공개 번역 세션 번호는 Chrome 동기화 저장소에 저장합니다. 방송별 수동 싱크와 익명 리액션용 무작위 브라우저 번호는 이 브라우저의 로컬 저장소에만 저장합니다.
- 확장프로그램 권한은 설정 저장을 위한 `storage`와 `weverse.io`, `www.instagram.com`, `api.cutiestreet.kro.kr`에 대한 사이트 접근으로 제한됩니다.
- 광고·분석·원격 실행 코드와 외부 추적 코드는 포함하지 않습니다. WebSocket용 Convex 브라우저 라이브러리도 확장프로그램 안에 고정된 파일로 포함합니다.

포함된 오픈소스 구성요소와 라이선스는 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)에서 확인할 수 있습니다.

## v1.15.0 Instagram 라이브 지원

- 영상 왼쪽에 빈 공간이 있으면 번역창을 그 공간에 자동 배치합니다.
- 위버스 라이브와 같은 실시간 자막, 싱크 조절과 이모티콘 리액션을 사용할 수 있습니다.

## v1.14.2 라이브 리액션과 지난 라이브 주소 지원

- 라이브 인간 번역 중 채팅 하단에 6개 이모티콘 버튼을 항상 표시합니다.
- 이모티콘을 누르면 영상 위에 바로 나타나고 같은 공개 번역 세션으로 전송됩니다.
- 다른 시청자가 보낸 새 리액션도 영상 위에 표시합니다.
- 지난 라이브가 `/media/...` 주소로 열려 자막창이 나타나지 않던 문제를 수정했습니다.

## v1.14.1 라이브 싱크 조작 개선

- 라이브 중에도 오버레이에 마우스를 올리면 자막 빠른 조절 버튼이 표시됩니다.
- 라이브 버튼도 다시보기와 동일하게 `− = 현재보다 늦게`, `+ = 현재보다 빠르게`로 통일하고 방향을 버튼에 함께 표시했습니다.
- 배경 설정을 일반적인 투명도 기준인 `0%=불투명`, `100%=완전 투명`으로 표시합니다. 기존 사용자의 실제 화면 투명도는 그대로 유지됩니다.

## v1.14.0 안정성 개선

- WebSocket 최신 자막보다 늦게 도착한 HTTP 응답이 화면을 과거 상태로 되돌리는 경합을 차단했습니다.
- 라이브가 끝나는 순간 이미 조회 중이어도 마지막 전체 자막 조회를 대기열에서 반드시 다시 실행합니다.
- 보관 번역의 수정·삭제도 반영하도록 HTTP 대체 연결에서 낮은 빈도의 전체 재확인을 추가했습니다.
- 설정을 조절하는 동안 자막 목록을 반복 생성하지 않아 스크롤 위치와 화면 읽기 흐름을 유지합니다.
- 위버스 게시물 응답이 콘텐츠 스크립트보다 먼저 도착해도 초 단위 라이브 시작 시각을 다시 전달하도록 안전한 재요청 절차를 추가했습니다.
- 해상도·재생 속도 하위 메뉴가 뒤늦게 열리는 경우까지 감지해 오버레이가 메뉴를 다시 가리는 문제를 막았습니다.
- 화면 밖의 영상과 다른 영역의 짧은 영상을 본편 광고로 잘못 판단하지 않도록 영상 선택 기준을 강화했습니다.
