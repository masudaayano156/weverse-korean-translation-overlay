Weverse·Instagram 한국어 번역 오버레이

시작 전 개인정보 안내

번역 자막과 라이브 기능에 꼭 필요한 범위만 사용하며, 로그인 정보나 개인 대화는 읽지 않습니다.

사용하는 정보

  • 화면 안에서만 확인: 지원 방송의 공개 주소·방송 번호·제목·시작 시각과 공개 번역 내용
  • 번역 서버로 전송: 공개 번역 세션 번호, 접속자 중복 방지용 무작위 익명 번호, 사용자가 누른 리액션 종류와 일회용 번호
  • 브라우저에 저장: 자막 위치·크기·색상·싱크 등의 설정, 방송별 수동 싱크, 동의 여부와 익명 번호

사용하지 않는 정보

  • Weverse·Instagram 로그인 정보, 비밀번호, 쿠키, 인증 토큰
  • 계정 이름·이메일·전화번호·실명
  • 댓글, 채팅 작성 내용, DM과 비공개 대화
  • 결제 정보, 위치 정보, 방문 기록 전체
  • 광고, 판매, 신용 평가 또는 사용자 프로파일링

왜 필요한가요?

공개 인간 번역을 현재 방송과 연결하려면 방송 번호가 필요합니다. 라이브 접속자 수를 한 사람당 한 번으로 세고 같은 공개 세션에서 리액션을 공유하기 위해 실제 신원과 연결되지 않는 무작위 번호를 사용합니다.

동의 전에는 번역 서버 연결, 접속자 집계, 리액션 전송, 번역 사이트의 익명 번호 확인을 시작하지 않습니다. 동의는 언제든 이 화면에서 철회할 수 있습니다.
